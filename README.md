# OOP with C++ Lab (PCS307)

![C++](https://img.shields.io/badge/Language-C%2B%2B17-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

This repository contains practical programs for **Object Oriented Programming with C++ Lab (PCS307)**.

The programs cover fundamental and advanced concepts of Object-Oriented Programming using C++.

---

## 📚 Topics Covered

- Classes and Objects
- Data Abstraction & Encapsulation
- Constructors & Destructors
- Function Overloading
- Static Members & Methods
- Operator Overloading (Member & Friend Functions)
- Inheritance (Single, Multiple, Multilevel, Hierarchical)
- Diamond Problem & Virtual Base Classes
- Runtime Polymorphism & Virtual Functions
- Abstract Classes & Pure Virtual Functions
- Exception Handling
- Function & Class Templates
- Standard Template Library (STL: List, Vector, Map)

## 🛠️ How to Compile and Run

To compile and run any practical program using `g++`:

```bash
# Navigate to the question directory
cd Q01-Electricity-Board

# Compile using C++17 standard
g++ -std=c++17 main.cpp -o main

# Run the executable
# Windows:
.\main.exe

# Linux / macOS:
./main
```
